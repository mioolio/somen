## 设计决定

- Vue 3 + Vue Router + Vite；Node.js 24 ESM 宿主，直接 `npm run dev`，本轮不执行生产打包编译。
- 自动发现 manifest 与前端注册文件；每平台独立服务注册和路由；注册失败回滚，移出/放回后重启生效。
- 首个插件识别 WeChat.exe / Weixin.exe，区分进程和实例，账号带证据；版本不支持或信息不足时待识别。
- 只读原生探测在有超时的子进程中；并发合并、成功结果短暂缓存，不持久化账号。
- API 和面板仅监听回环地址，校验 Host、请求来源。
