# 微信版本兼容

每个客户端版本独立保存，目录名必须与 DLL 文件版本一致。

```text
versions/
  4.2.0.7/
    manifest.json       版本身份、DLL SHA-256、独立能力声明
    identity.json       只读账号指针、偏移、代码校验
    agents/             本版本联系人、发送等原生适配
    compatibility.md    可选：静态分析与实机验证证据
  4.2.0.11/
    ...
```

通用宿主不保存具体微信版本的偏移。账号读取器扫描版本目录内的 `identity.json`；原生运行时读取对应目录的 manifest 和 agent 文件。没有中央版本列表。

每个功能单独标记支持状态。通过账号读取验证不等于发送 ABI 已验证；文字发送通过也不等于图片或表情包通过。DLL 名称、完整版本、x64 架构、SHA-256、代码字节与必要运行态结构均需核对。

增加版本时先离线核对函数、调用关系和数据布局，再进行账号及功能实测，记录证据。不能仅因为版本接近、字符串或归一化指令相似就开启原生调用。

移出一个版本目录只影响该版本；缺失、损坏或未验证的功能保持不可用，进程枚举和诊断继续工作。不从其他版本借用偏移兜底。
